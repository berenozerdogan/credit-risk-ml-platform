# Credit Risk Scoring Platform

## Problem Statement
Banks need to evaluate loan applications efficiently while minimizing default risk.
This project builds an end-to-end machine learning system that predicts credit risk,
provides explainable decisions, and supports real-time deployment.

## Objectives
- Predict loan default risk using machine learning
- Explain model decisions using SHAP
- Deploy a live web application
- Monitor model performance over time

## Tech Stack
- Python, Pandas, Scikit-learn, XGBoost
- FastAPI
- PostgreSQL
- React / Next.js
- Docker, Cloud (AWS/GCP)
